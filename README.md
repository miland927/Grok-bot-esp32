# GrokBot ESP32

GrokBot 是运行在 **Waveshare ESP32-S3 Touch AMOLED 2.06** 上的桌面小球。语音、联网和手机热点配网沿用 XiaoZhi，脸部和触摸反馈在设备上实时绘制。

- **换电脑继续开发**：[跨电脑交接、构建、同步与验收记录](docs/pet/HANDOFF.md)
- **功能与手势**：[小球和互动演出](docs/pet/README.md)
- **microSD**：[烟花、TNT、图腾和脸部配置](docs/pet/MICROSD.md)
- **电脑端原型**：[顶部设置面板](docs/pet/preview/top-controls.html)

`main` 是跨电脑的同步入口。普通克隆使用仓库内的原创默认素材。机主的私人素材可以独立放入 `local-only/` 和 microSD。

历史鲸鱼娘实验和管理工具的资料在 [docs/whale](docs/whale/)，当前 GrokBot 使用独立构建变体。
