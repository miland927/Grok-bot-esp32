## 在其他电脑复现试验

仓库默认源码和资源保留已验收的v3。试验补丁、资源生成脚本和清单独立保存。先完成容量记录中的常用10项转换，随后在干净的试验分支执行：

```sh
git switch -c trial-v4 9e8799d
python scripts/whale/pack_common_whale_assets.py --repo . --candidates local-only/common-ten --output local-only/common-ten-package
git apply --unidiff-zero --check docs/whale/trials/v4-160px.patch
git apply --unidiff-zero docs/whale/trials/v4-160px.patch
python -c "import shutil; shutil.copyfile('local-only/common-ten-package/assets-common-ten-160px.bin', 'whale/assets.bin')"
python scripts/whale/build.py
```

此试验的资源由`pack_common_whale_assets.py`生成；原`build_assets.py`仍服务于三种224px基线，会重建旧素材。编译镜像可能随构建时间与环境改变哈希，重新核对实际输出。

本轮只更新既有ota_1应用0x1000000和资源0x1600000，不重新写启动、分区、NVS、factory或ota_0。不要使用生成日志里的通用整机刷写命令。v3应用和资源在原电脑独立保留；私人刷写工具、设备身份、原始日志和备份未上传Git。
