## 配音设计

时间从第五次有效松手计。用少量有来源记录的素材或合成拟音做一条 **3.50 s 单声道**轨道，围绕 Grok 忍耐逐渐失控来配。先在电脑上混音，尽量避免动态范围过大，爆炸保留瞬态且无削波。主观试听以小扬声器上能区分三段蓄力和停顿为准。

| 时间 | 设计与验收 |
| --- | --- |
| 0.00–0.25 s | 近乎无声，给收眼和紧绷表情留空间。 |
| 0.25–0.45 s | 一次短促变形拟音，随拉伸过渡进入 TNT 形态。 |
| 0.45–0.95 s | 一段轻而短的挤压与回弹声。 |
| 0.95–1.50 s | 第二段更沉、更紧，回弹有更清楚的重音。 |
| 1.50–2.20 s | 第三段更密、更急，低频压力与细碎颤动叠加，在 2.20 s 前收掉尾音。 |
| 2.20–2.35 s | 极短吸气可放在窗口开头，其余留空。停顿听得出来，蓄力尾音或混响不跨进爆炸。 |
| 2.35 s | 爆炸首瞬态对齐白闪帧。主体音可持续至余波开头。 |
| 2.55–3.10 s | 余波逐渐变远，灰烟和碎片带少量轻响，电平衰减。 |
| 3.10–3.50 s | 烟雾散去，让发懵的小球回来。尾音降到静音，保持自然。 |

先交一版声音和画面对拍，60 FPS 和 20 FPS 均从第 0 帧合成。保存原音/合成脚本或混音工程及来源说明，导出用于固件的 Ogg Opus，并记录 SHA-256、时长和大小。爆炸音起点目标 2350 ms，离线合成检查误差不超过 20 ms。原烟花的轨道、资源包和素材继续原样使用。

## 固件落点

- [pet_display.cc](../../main/display/pet_display.cc) 的 `ScreenEventCb()` 在 `tnt_.Tap(now)` 返回 true 时是唯一的 TNT 启动入口。`Tick()` 每帧调用 `tnt_.Update(now, idle)`，负责在离开 idle 或演出结束时恢复原脸。音轨启动请求绑定到本次演出的同一个起点和标识，跳 Tick 与重复触摸都不得重复启动音轨。
- [pet_tnt.cc](../../main/display/pet_tnt.cc) 的 `kStageEndsUs` 与 `Sample()` 是画面时间轴的权威。保留其纯计算和 RGB565 绘制，主机预览继续用 [tnt_preview.cc](../../scripts/pet/tnt_preview.cc)。不在绘制路径播放、分配音频缓冲或访问 SD。
- 参考 [pet_fireworks.cc](../../main/display/pet_fireworks.cc) 的 `StartAudio()`，把可能等待队列的 `AudioService::PlaySound()` 放在受限后台执行路径。实际启动前再检查 `kDeviceStateIdle`、`IsPlaybackIdle()` 和本次演出标识，忙或过了入点就让该次演出静音。限制为同一时间一个 TNT 音轨。通过线程安全的状态/标识和播放取消回调处理语音打断、结束与销毁；避免任务持有裸 `PetDisplay*`。
- [audio_service.cc](../../main/audio/audio_service.cc) 的 `PlaySound(ogg, continue_playing)` 在提交每个包前检查回调，已经入队的包可能还有短尾。专项测试要覆盖语音中断、回到 idle 后旧音轨不复播，且新一轮能正常开始。不要为 TNT 清全局解码队列、停语音或改变现有音频优先级；若残尾可闻，先测并报告，再做 TNT 范围内的处理。
- 在 [main/CMakeLists.txt](../../main/CMakeLists.txt) 的普通 GrokBot 变体里参考已有可选本机音效嵌入条件。首选一条小的可选内置轨道，建议不超过 48 KiB。音效缺失、无效、队列忙或启动失败时，完整视觉照常播放。TNT 继续支持无卡，保持烟花 GRA1、microSD 读取、原音效防重入和脸部热重载逻辑。禁止引入 SD 写入。

## 带声样片视觉复审 · 本轮先做这两处

对照 `local-only/tnt-preview/tnt-cinematic-texture-20fps-410x502-sound.mp4`。已抽查 0.75、2.00、2.30、2.40、2.60、2.80、3.10 和 3.25 秒。带声版的两处反馈可直接定位到 [pet_tnt.cc](../../main/display/pet_tnt.cc)。

1. **移除方块顶部的引线和火星。** `DrawCrate()` 绘制 16×16 正面纹理之后，另画了棕色线段和黄色火花。删掉这三个叠加图元及专用的局部 `rect` 函数。保留方块纹理和蓄力变形、推镜、停顿，重新核对 `Bounds()` 是否仍需为头顶留空。验收看 0.75、2.00、2.30 秒，方块轮廓上方全程干净，顶上没有线或常驻火花。这里的“引线”指画面图元，本次沿用现有 `Fuse.ogg` 混音。
2. **替换爆后的白絮粒子。** 2.60–3.10 秒画面里的灰白圆团来自 `DrawSmoke()`。它用 13 个亮色块沿固定角度扩散，后期围成空心花环。保留 `DrawBlast()` 的短白闪与冲击波，把余波改成从爆心出发的低饱和暗灰粉尘，先向左右推开，再少量向上卷起并消散。首轮用 6–8 簇不规则像素尘，大小、速度和寿命错开，中间保留少量落下的暗红碎片。粉尘从密到疏、由暗灰淡回背景，3.10 秒以后只留少量贴边薄尘，小球的眼睛先清楚出现。保持固定种子或固定参数表，沿用现有局部刷新。若换用贴图，先附来源和预览供用户确认。

**验收。** 保留 2.20–2.35 秒吸气停顿、2.35 秒爆炸与 3.10 秒回场。对照检查 2.60、2.80、3.10、3.25 秒，无亮白絮状团块或完整烟圈，粉尘有方向且逐步消散，脸回归时轮廓和眼睛清楚。用同一条音轨重新导出 60/20 FPS 带声样片，另存并跑 `python scripts/pet/tnt_sound_check.py` 复核声画同步。先交这两版给用户看，刷机另等确认。
