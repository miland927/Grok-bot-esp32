# 桌面小东西 · 路线图

> 目标：一台**长期通电、有存在感**的桌面陪伴设备。
> 不是"能跑 demo 的开发板"，是"放在桌上会自己活着的东西"。
> 语音能力来自小智云（ASR/LLM/TTS），脸和性格是本地程序化渲染。

当前状态：语音 + 绑定 + 程序化脸 + 触摸手势 + IMU + 声音反应 + 打瞌睡 + MCP 表情工具，均已跑通。

---

## 阶段一：让它"活着"（1–2 周）

| # | 任务 | 做法 | 验收 | 状态 |
|---|---|---|---|---|
| 1.1 | **麦克风电平驱动表情** | `AudioService::ReadAudioData` 里挂只读电平回调，不动 AEC | 说话时眼睛随音量变化 | ✅ |
| 1.2 | **IMU 反应** | QMI8658 @0x6B，拿起=惊讶，摇晃=晕，倾斜=视线偏移 | 三种反应都有 | ✅ |
| 1.3 | **手势** | 单击跳、双击转圈、长按眯眼、拖动跟随 | 四种手势不冲突 | ✅ |
| 1.4 | **昼夜节律** | PCF85063 + SNTP 对时并回写 RTC；23:00–07:00 眼睛 0.8×、呼吸变慢 | 实测 `sntp synced 2026-11-03 00:08:07`，RTC 星期同步修正 | ✅ |
| 1.5 | **点击音效** | 复用 `OGG_POPUP`，仅在 `kDeviceStateIdle` 时播，绝不打断对话 | 点击有声且不打断对话 | ✅ 待听感确认 |

## 阶段二：性格（2–4 周）

| # | 任务 | 做法 | 验收 | 状态 |
|---|---|---|---|---|
| 2.1 | **状态机** | 优先级阶梯：触摸 > 眩晕 > 情绪 > 说话 > 聆听 > 瞌睡 > 待机 | 切换不跳变 | ✅ |
| 2.2 | **微动作库** | 12–40 秒随机：张望 / 连眨两下 / 小跳 / 叹气 | 日志可验（`idle hop` 等） | ✅ |
| 2.3 | **说话时联动** | TTS 包络驱动眼部起伏 | 说话时脸在动 | ✅ |
| 2.4 | **MCP 表情工具** | `self.pet.set_mood` / `self.pet.look_at` | 模型能主动演 | ✅ |
| 2.5 | **记忆钩子** | 120 秒无互动打瞌睡，被碰惊醒 | 放一会儿回来会"吓一跳" | ✅ |

## 不做什么

- **不刷第三方系统**：屏幕/触摸/音频驱动全要重写，且会丢掉语音能力
- **不做视频播放**：屏幕是给脸用的，不是给内容用的
- **不做通用 App 平台**：这台设备的价值是"一个角色"，不是"一台小手机"
